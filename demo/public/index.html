05

제한된 성능 검증

p50·p95·p99, 처리량, 상태 코드, 토큰 사용량과 429 발생을 측정합니다.

Bedrock는 입력 토큰과 maxTokens를 기준으로 TPM을 예약합니다. 목적에 맞게 maxTokens를 줄인 뒤 단계적으로 동시성을 높이세요.

성공률은 최종 HTTP 응답 기준입니다. 데모는 요청당 한 번 호출합니다. 요청 전체 SDK 지표는 검색·생성 등 공통 AWS 호출 경로를 집계하며 일부 메타데이터가 없으면 미측정입니다. 생성 호출과 실패 호출 지표도 따로 제공합니다. 타임아웃 뒤 서버 처리 완료 여부는 알 수 없습니다. HTTP 504는 기타 HTTP 실패로 집계합니다.
