# Service Demo 개인정보·로그 정책

- 적용일: 2026-08-31
- 적용 범위: `service-demo/` 브라우저와 BFF

## 수집과 보존

- 서비스 데모는 질문, 답변, 이메일, 전화번호, 주문번호를 자체 데이터 저장소에 영구 저장하지 않습니다. 서비스 데모 보존 기간은 0일입니다.
- 프레임워크 접근 로그에는 method, path, status, 처리 시간만 사용하며 request body, cookie, appkey, 운영자 키를 기록하지 않습니다.
- 화면에는 사용자 식별정보 대신 가상 ID와 correlation ID만 표시합니다.
- AI Server의 질의 감사 로그는 별도 서버 운영 정책 범위이며, 서비스 데모 BFF는 대표 개인정보 형식을 AI Server 전송 전에 차단합니다.

## 입력 차단

- 이메일 주소
- 국내 휴대전화 번호
- 주민등록번호 형식
- `주문번호` 또는 `order number`로 명시된 식별자

차단 응답은 입력 원문을 되돌려주지 않고 correlation ID만 제공합니다. 일반 상품명, 상품코드, 가격, 운영·정책 질문은 계속 허용합니다.

## 인증정보 비노출

- appkey, 지식 운영자 키와 로컬 역할 토큰은 서버 전용 환경변수와 HttpOnly cookie에만 존재합니다.
- 고객, 상담원, 관리자 페이지 응답의 실제 secret 일치 검사는 0건이어야 합니다.
- 상담원·관리자 권한 API는 허용 이메일이나 로컬 토큰 값을 응답하지 않습니다.

## 검증 증거

- 비인증 상담원 API: HTTP 403
- 상담원 로컬 세션 및 권한 확인: HTTP 200
- 개인정보 포함 질문: HTTP 400 `SENSITIVE_DATA_NOT_ALLOWED`, AI Server 미호출, 입력 원문 비반사
- 일반 지식 질문: HTTP 200, 근거 답변 유지
- `/`, `/chat`, `/agent`, `/knowledge` 응답: secret 일치 0건
