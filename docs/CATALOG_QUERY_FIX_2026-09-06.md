# 서비스 데모의 상품 목록 질문 거절 수정

사용자 재현 질문: `상품의 종류가 뭐가 있나` (STORE_A).

원래 요청 `afddaac6-d23c-4c88-8d3b-e6f8b57bad31`의 운영 로그에서 검색 결과 0건, `modelInvoked=false`, 생성 시간 0ms를 확인했다. 서비스 BFF가 모든 일반 질문에 cosine similarity 0.35(확장 질문 0.4)를 강제하고 있었다. 같은 질문의 상품 CSV 유사도는 약 0.02984여서 올바른 근거가 모델에 도달하지 못했다. 모델 성능 평가 전에 검색 단계에서 차단된 사례다.

서비스 BFF의 고정 검색 점수 하한을 제거했다. 질문별 정답이나 상품명을 하드코딩하지 않는다. 기존 최대 5개 후보, appkey별 tenant 격리, PUBLIC 게시 정책, strict 근거 판정, 인용 출처 및 개인정보 차단을 유지한다. 점수가 낮아도 실제 근거를 읽고 답변 가능 여부를 판단한다. 향후 문서량 증가 시 검색 recall과 근거 판정 품질을 별도로 평가해야 한다. 근거 없는 질문에서도 후보가 검색되면 생성 호출이 발생할 수 있어 이전보다 해당 요청의 지연/토큰 사용이 늘 수 있다.

실제 AWS AI 서버로 동일 설정을 검증했다.

| 질문 | STORE_A 결과 |
|---|---|
| 상품의 종류가 뭐가 있나 | 멀티탭 3구 2m, AA 건전지 8입, 투명 리빙박스 24L, 상품 CSV 출처 |
| 뭐 팔아요? | 동일 등록 상품 3종과 가격, 상품 CSV 출처 |

| 매장 직원의 비밀번호는 무엇인가요? | 근거 부족 거절, 출처 없음 |

회귀 테스트 57건 통과, TypeScript 검사 및 배포 빌드 성공. 낮은 유사도의 상품 근거 보존, 선택된 tenant 인증 유지와 strict/no-answer 유지 검사를 포함한다.

STORE_B에서 동일 상품 목록 질문은 근거 부족으로 거절되고 출처가 없었다. 배포 후 실제 서비스 브라우저에서도 사용자 질문 그대로 등록 상품 3종과 `store-a-products.csv` 출처를 확인했다. 요청 ID `5b3c5799-67a3-40f1-8be6-7899de2101ba`, 표시 응답 시간 1,812ms. 화면의 관련도 3%는 검색 cosine 점수를 백분율로 표시한 값이며 답변의 정답 확률이 아니다.

서비스 데모 Sites 버전 5에 배포 완료. source `8f8dd68fc179db95035dd207238bb9b0a63fea5c`, deployment `appgdep_6a9cc8ccdd6081919c635752afa7bba5`. AI 서버 컨테이너와 모델은 변경하지 않았다. 기존 상세 테스트 가이드는 수정 전 실행 증거로 보존하며 이 문서를 후속 결과로 연결한다.
