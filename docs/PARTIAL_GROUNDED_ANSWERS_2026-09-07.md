# 부분 근거 답변 개선 — 2026-09-07

상태: 로컬 구현. AWS 세션 만료로 운영 배포와 실제 모델 회귀 검증은 미실행.

`rag-answer-v3-partial`은 질문 전체를 확정할 수 없어도 직접 관련된 일부 사실을 출처와 함께 답하도록 한다. 관측된 일부를 전체로 일반화하지 않으며, 모르는 범위를 답변에 명시한다. 공개 JSON 구조는 유지한다. `answerable: true`는 출처로 뒷받침되는 유용한 부분 답변도 포함하며, 부분 여부를 나타내는 새로운 API 필드는 추가하지 않았다.

예상 동작:

- 매장 구조: 1층 A-04에 멀티탭·건전지, 2층 C-02에 리빙박스가 있다는 자료를 설명하고 전체 평면도는 미확인이라고 안내.
- 총 층수: 1층과 2층 사용은 확인되지만 다른 층 존재 여부와 총 층수는 확정할 수 없다고 안내.
- 계단 위치·3층 상품: 관련 근거가 없으므로 거절. 모르는 시설·상품을 만들지 않음.

수정: 서버 출력 지침 및 질문 프롬프트, 부분 답변/출처 검증 단위 테스트, 품질 평가 스크립트의 구조·층수·계단·3층 사례. 문서 충돌 시 임의 선택 금지와 유효한 출처 요구는 유지한다.

로컬 빌드 시 임시 서비스 배포 체크아웃이 서버 TypeScript 입력에 포함되는 기존 설정 문제가 드러나 `work`, `outputs`를 컴파일 대상에서 제외했다. 다른 서비스의 React 코드를 AI 서버 빌드에 섞지 않도록 한 변경이다.

운영 검증은 인증 복구 후 현재 운영 릴리스와 변경분을 대조하고, 이 작업의 변경만 적용한 릴리스를 빌드해 수행해야 한다. 관련 없는 로컬 미커밋 변경을 운영에 함께 배포하지 않는다. 단위 테스트는 모델의 추론 품질을 증명하지 않으므로 실측 전 성공률을 주장하지 않는다.
